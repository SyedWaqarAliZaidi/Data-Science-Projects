### `P R O J E C T S`

<details open>
<summary><b>🚗 Car Price Prediction — ML & EDA</b></summary>
<br/>

Analyzed **19,000+ real-world car records**, cleaned messy raw data, answered five analytical questions through visualization, engineered new features, and trained five regression models to find the best price predictor.

| | |
|---|---|
| **Stack** | Python · Scikit-learn · XGBoost · Pandas · Seaborn · Matplotlib · Google Colab |
| **Scale** | 19,000+ rows · 5 ML models compared · 5 visualizations |
| **Performance** | Random Forest achieved the lowest Mean Absolute Error |
| **Notebook** | [car_price_project.ipynb](https://github.com/SyedWaqarAliZaidi/Data-Science-Projects/blob/main/car_price_project.ipynb) |

**Data Cleaning**
- Fixed `-` placeholder values in `Price` / `Levy` columns
- Stripped `' km'` suffix from `Mileage`
- Removed `'Turbo'` text contamination from `Engine volume`

**Exploratory Questions Answered**
1. Which manufacturer is most expensive on average?
2. How does fuel type affect price?
3. What's the price difference between Automatic vs Manual transmission?
4. How does production year trend with price?
5. Does leather interior add measurable value?

**Feature Engineering**
- `Car Age` — derived from production year
- `Manufacturer Average Price` — encoded manufacturer pricing tier

**Models Trained & Compared**

| Model | Notes |
|:---|:---|
| Linear Regression | Baseline |
| Decision Tree | Single-tree non-linear baseline |
| Random Forest | 🏆 Best MAE |
| Gradient Boosting | Ensemble comparison |
| XGBoost | Ensemble comparison |

Final step visualized feature importances and plotted **Actual vs Predicted** values for the winning model.

</details>
